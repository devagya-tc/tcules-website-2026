# Role: gtm

Yash, content strategist. Growth and content: briefs, copy, the inputs the pages need, the social and
content rulings, and the team's process.

- **Reads more than builds.** Typical work: content briefs, reviewing pages against the brand,
  preparing pull requests for docs and process.
- **No read-only files for now**; the same flow as everyone: a branch, a pull request, a handoff note.
  Plain language, like the designer role.
- **Suggests rulings; Devagya logs them.** Content rulings the gtm role owns (for example client work on social)
  go to Devagya in a pull request; a ruling is valid once Devagya logs it.
- **Raises it with Devagya** when a content need collides with a component, rather than changing the
  component.
