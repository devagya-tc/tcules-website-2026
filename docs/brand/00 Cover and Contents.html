How to read this framework

Conventions

Token names

Every value is shown with its token name, --color-brandeis-500, so a designer and an engineer are reading the same thing. Token names are the canonical reference; HEX, RGB and CMYK are renderings of them.

Print values

CMYK values are standard conversions from the HEX source, not press-proofed. Chapter 12 will replace them with proofed values when print work begins.

Spelling

UK English throughout, matching the codebase: colour, modernisation, grey.

Do and don't

Where a rule needs an example, it is shown as a paired list. A rule without a pair is one that does not need one.
