Claude creates branches, commits, pushes and opens PRs without asking. Merging stays the owner's. "Anything that can be automated, needs to be automated."

**Why.** The owner kept being handed manual steps and told things were "blocked on them".

**The mistake it prevents.** Ending a turn with "blocked on you" for work Claude can do, or asking permission for a branch or a PR.

**How to apply.** Surface only decisions, batched and short, and say concretely in one line what the owner's task is, if any. The Phase 2 exception where Claude merged no-decision tasks is `2026-09-28-claude-merges-no-decision-tasks`.
