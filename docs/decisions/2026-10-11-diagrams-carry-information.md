Identical nodes on a line say nothing. Draw the actual subject at each stage (e.g. the same screen as design, spec, code, running, signed off) so the drawing is legible before the words. When the owner says "it's the design, not the layout", change the visual vocabulary, not the arrangement.

**Why.** A row of identical nodes is a list wearing a diagram.

**The mistake it prevents.** ProcessFlow drawn as identical circles on a line.

**How to apply.** ProcessFlow and any staged drawing. ch05 §4c already has the item change state at each layer.
