A case example band focuses on what matters in the case: problem → what we did → outcome, with the evidence image, read in that authored order and joined as one connected sequence. Not a generic card.

**Why.** A claim-first split, with the result on top and the backstory in a ruled row below, felt "disconnected".

**The mistake it prevents.** The Dealpath example as a generic card, then as a result-first split.

**How to apply.** Any single-case band.
