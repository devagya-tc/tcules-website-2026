The same job uses the pattern already iterated for it: symptoms/questions → VoiceLedger; deliverables/principles → OfferSheet; why → alternating banners; an unquoted case → a horizontal case card.

**Why.** Each of these was iterated with the owner; inventing a new shape for the same job throws that work away.

**The mistake it prevents.** A second, unreviewed design for a job the kit already answers.

**How to apply.** Before designing a band, name its job and check whether a pattern already serves it.
