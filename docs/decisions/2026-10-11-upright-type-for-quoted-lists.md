Italic serif reads poorly at list sizes. Quoted complaints and claims are set in upright type; italic only for a single short display quote, if at all.

**Why.** A list of italic serif lines was hard to read.

**The mistake it prevents.** VoiceLedger-style rows of italic complaints.

**How to apply.** Any list of quoted lines. ch03 §6 shows italic as an emphasis device but says nothing about list sizes.
