Inside a band, one type size per role. Emphasis is marked with a rule or colour, not a size bump. Actions align to the section edge, not to an inset text column.

**Why.** The Dealpath result was set larger than its story, and the owner asked for the same size across the body.

**The mistake it prevents.** A result line bumped a size above the story around it.

**How to apply.** Every band. ch03 §6 already makes the point ("three sizes on a card").
