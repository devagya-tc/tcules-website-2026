"Display text should only be used for heros. any other section should use h1/h2 depending on the prominence it requires."

**Why.** Display outside the hero flattens the page's hierarchy; the hero should be the one display moment.

**The mistake it prevents.** The home gateway band heading set at display size.

**How to apply.** Section heads below the hero take `--text-h1` for the most prominent bands, `--text-h2` otherwise. Check every new pattern variant and specimen for display use. ch03 §5 does not say where display may appear.
