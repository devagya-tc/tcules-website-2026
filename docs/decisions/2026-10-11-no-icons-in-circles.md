"Don't put icons in a circle." No icon discs.

**Why.** A glyph in a disc is a badge competing with the words it serves.

**The mistake it prevents.** Gateway items with glyphs set in coloured discs.

**How to apply.** Any glyph; the enquiry close's entry glyph is bare. ch04 §8 already shows "Glyphs in coloured discs" as a Don't.
