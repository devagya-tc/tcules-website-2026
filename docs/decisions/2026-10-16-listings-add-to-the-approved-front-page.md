The listings start from the approved insights front page (feat/insights-front-page) and ADD navigation: a By type / By topic switcher, because there are two layers. "The design on main looks much better. It just lacks that navigation." The goal for these pages is beauty; the bar is the top 1% of visual design.

**Why.** PR #112 was "made functional but not beautiful": it replaced approved work instead of adding to it, losing the display title and the 3D format tiles (Articles / Podcasts / Interviews / Events).

**The mistake it prevents.** PR #112: a typographically absent TOC, an empty featured row, a four-column "Start with your problem" block ("what even is this?").

**How to apply.** Any listing redesign. "Main" here meant the insights front page branch, not the main branch.
