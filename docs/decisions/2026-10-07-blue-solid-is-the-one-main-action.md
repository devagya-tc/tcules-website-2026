No neutral or ink solid buttons. Blue solid is for the one main action on a page (the hero and/or the bottom CTA); everything else is a link button. This reverses fix/tone ("converts blue, else ink").

**Why.** Several solid buttons compete; one blue action is the page's ask.

**The mistake it prevents.** The fix/tone pass that set solids to ink wherever they did not convert.

**How to apply.** Button variants and every CtaRow. ch02 §7 defines the accent as "the one saturated element in a band", not one per page.
