Never use an arrow as a decorative marker on non-interactive rows. Use a mark that says what the thing is (e.g. quote marks for speech).

**Why.** An arrow promises a destination.

**The mistake it prevents.** Arrow bullets on static lists.

**How to apply.** Any list marker. ch04 §7 lets icons "mark list rows" without restricting arrows to actions.
