Lines go only where they structure something (a card edge, a header strip), never between every row. Every item has a complete anatomy, never floating text.

**Why.** PR #112 had far too many hairlines: two columns of ruled rows read misaligned and ugly, and its featured row was a big image beside a tiny date and title "floating in space".

**The mistake it prevents.** PR #112's ruled listings.

**How to apply.** Any list or listing. Count the rules in a band and remove each one that separates nothing.
