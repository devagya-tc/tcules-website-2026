In Q&A, the question must clearly out-rank the answer by weight, size or ink.

**Why.** Questions and answers set too close in type read as one block.

**The mistake it prevents.** An Accordion whose question and answer were near-identical in weight.

**How to apply.** Accordion and any Q&A composition.
