"The goal is to have one view of the project that holds the title, description, testimonial, visual." The visual is an input, a fixed slot (the case cover). The design problem is that one view: its surface, frame, type contrast, graphic detail and motion, judged as a single beautiful object.

**Why.** Round 3 spent its effort "ideating on the visual asset of the project": cut-outs, dot fields, diagrams, a mosaic.

**The mistake it prevents.** Remaking the project image instead of designing the card.

**How to apply.** "Think textures, graphics" applies to the view, not to the project image. Case imagery is ch05 cut-outs made from the captures; whole-screen screenshots are banned there.
