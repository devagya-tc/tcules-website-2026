The rules for client marks in a set (source, colour, size and exclusions) are the ones in ch05 §10.
In a set of marks, a logo strip or a client wall, every mark is one colour: the ground's ink,
`--color-neutral-900` on paper and paper-deep, `--color-white` on ink. Never the clients' own colours
inside a set, never a tint or an opacity. A mark shown alone, beside its own case study, may be the
client's full-colour version.

**Why.** The 16 Sep amendments found the logo-wall rules existed only in the framework outline, not
in the chapter, so nothing could be built against them. The owner brought them into §10.

**The mistake it prevents.** A logo strip in clients' brand colours, or greyed out with opacity,
which turns a set of proof into a patchwork.

**How to apply.** Logo strips and walls render each mark monochrome in the surface's ink. Full colour
only on a single mark beside its own case study.
