Items beside an image that extend into the next row past the image are an illegal layout. Either all items sit beside the image, or the image goes and the set runs alone.

**Why.** The set loses its column and the image loses its pairing.

**The mistake it prevents.** "What makes the practice different", where the set ran on under the photograph.

**How to apply.** Any image-beside-set composition, checked at every width.
