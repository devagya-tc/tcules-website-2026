The top layer is the latest, the target or the end goal. Nothing flows down except a return path that means recovery or feedback. The item changes FORM at every layer, and every device means something where it sits.

**Why.** The Intent Stack works because its item rises and changes state.

**The mistake it prevents.** Stacks where the item flows downward for no reason.

**How to apply.** Any layered illustration. ch05 §4c shows this in the Intent Stack but §4b does not state it as a rule.
