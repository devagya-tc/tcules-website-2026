# Tcules Copy × UI Quality Standard

A page must pass both the Copy Quality Standard and this standard.

Copy quality asks: **Is this true, useful, differentiated, coherent and well written?**

Copy × UI asks: **Can this content inhabit a high-quality interface without damaging hierarchy, rhythm, comprehension, responsiveness or aesthetics?**

## A. Component fitness

### CU01 — One primary communication job — HARD GATE
A component should primarily orient, explain, differentiate, prove, reassure or prompt action.

Test: “After seeing this component, the reader should understand ______.”

If several unrelated answers are required, restructure.

### CU02 — Respect the component type
A heading advances an idea. A card distinguishes one item. A button names an action. A label identifies. Helper text assists. A testimonial proves. A stat quantifies. A caption contextualises.

### CU03 — Repeated components share a semantic contract — HARD GATE
If components look alike, readers assume they are comparable.

Sibling cards must describe the same conceptual dimension at a comparable abstraction level.

### CU04 — Use content budgets, not quotas
Default ranges:

| Element | Preferred range |
|---|---:|
| Eyebrow | 2–5 words |
| H1 | 4–10 words |
| H2 | 3–10 words |
| H3/card title | 2–8 words |
| Hero support | 15–35 words |
| Section intro | 15–45 words |
| Standard card body | 15–45 words |
| Compact card body | 8–25 words |
| CTA | 1–5 words |
| Navigation label | 1–3 words |
| Stat descriptor | 2–8 words |
| Caption | 5–20 words |

These are starting constraints, not reasons to weaken meaning.

### CU05 — Survive content variance
Test shortest and longest plausible content, proper nouns, numbers and mobile widths. The system must not rely on ideal-length placeholder copy.

## B. Information hierarchy

### CU06 — Visual prominence matches semantic importance — HARD GATE
Normal progression:
**proposition → qualification → evidence → detail → action**

### CU07 — One dominant proposition per major heading
Do not compress headline, audience, mechanism, qualification and benefit into one typographic object.

### CU08 — Supporting copy adds information
Support must qualify, explain or make concrete. It must not paraphrase the heading.

### CU09 — Specificity increases down the page
Move from orientation towards mechanisms, examples, artefacts, cases and evidence.

### CU10 — Heading-only read remains coherent — HARD GATE
Read only H1, H2s, H3/card titles and CTA labels. They should form a meaningful argument.

## C. Density and rhythm

### CU11 — Vary density intentionally
Do not let every section become a similarly sized heading + paragraph + three cards pattern.

Alternate communication modes where useful: compressed proposition, visual, evidence, explanation, interaction, whitespace.

### CU12 — Empty space is valid
Never add copy merely because the component has room.

### CU13 — Fix editorial problems before shrinking typography
Order:
1. delete;
2. prioritise;
3. combine;
4. move detail;
5. rewrite;
6. restructure component;
7. only then reconsider typography.

### CU14 — Balance repeated components
Sibling items should have intentional visual weight. For ordinary equal-card groups, ±30% around the median copy length is a useful review flag, not a hard target.

### CU15 — Avoid repetitive section geometry
Five attractive sections can still create a monotonous page if they use the same composition pattern.

## D. Language architecture

### CU16 — UI similarity requires grammatical parallelism — HARD GATE
Repeated elements normally align in grammatical person, tense, sentence type, abstraction level and syntactic role.

### CU17 — One concept gets one preferred name
Do not rotate terminology for elegance when the underlying object is the same.

### CU18 — Prevent vocabulary leakage
Internal terms such as ICP, demand trigger, responsibility taxonomy or claim lineage should not surface unless they genuinely help the visitor.

### CU19 — Recognition beats cleverness
Priority:
**recognition → clarity → distinction → memorability → wit**

### CU20 — Remove semantic redundancy
Review meaning, not only repeated phrases. Two differently worded components can still say the same thing.

## E. Interaction copy

### CU21 — CTA predicts the resulting action — HARD GATE
Prefer:
- View case study
- See our work
- Start a conversation
- Read the approach

Avoid vague controls such as Explore, Discover more or Click here when context does not make the destination explicit.

### CU22 — Commitment matches readiness
Do not demand a high-commitment sales action before the reader has enough context or proof.

### CU23 — Functional UI copy prioritises clarity — HARD GATE
Forms, errors, filters, inputs and confirmations are functional systems first and brand moments second.

### CU24 — Links and controls survive outside surrounding prose
Where several links appear, prefer contextual labels over repeated “Learn more”.

## F. Responsive aesthetics

### CU25 — Responsive viability — HARD GATE
Inspect at meaningful breakpoints, including desktop and narrow mobile.

Flag awkward headline wrapping, multi-line buttons, excessive card-title wrapping, accidental orphan words, very tall mobile text blocks and sibling cards with visibly broken balance.

### CU26 — Avoid authored line breaks for decoration
Let responsive typography wrap naturally unless the break carries meaning.

### CU27 — Mobile reading cost is independent
Desktop whitespace can disguise excessive copy. Evaluate vertical scroll and reading effort on mobile.

## G. Page composition

### CU28 — Every section advances the argument
Ask: “What does the reader know after this that they did not know before?”

If the answer is only the same idea in new wording, remove or merge it.

### CU29 — Evidence sits near the claim it substantiates
Do not make readers remember an unsupported claim for several screens before seeing proof.

### CU30 — Change communication mode deliberately
A strong page should move through different ways of knowing, for example:
**proposition → recognition → explanation → demonstration → evidence → reassurance → action**

This is not a mandatory sequence. It is a rhythm principle.

## H. Visual opportunity

### CU31 — Text must justify remaining text
For any explanation longer than roughly one compact paragraph, test whether a diagram, annotated artefact, workflow, comparison, data visual or actual product image would communicate better.

### CU32 — Visuals have communication jobs
Every proposed visual should primarily orient, demonstrate, explain, prove, humanise or relieve necessary density.

Decorative imagery can support art direction, but it must not be counted as communication or proof.

### CU33 — Product work should be shown where possible
For Tcules, actual product artefacts usually carry more credibility than generic illustration. Case studies, service mechanisms and AI interactions are strong candidates for annotated or sequenced real-product visuals.

# Scoring

## Hard gates
A failure blocks component/page approval:
CU01, CU03, CU06, CU10, CU16, CU21, CU23, CU25.

## Quality criteria
Score the remaining applicable criteria:
- 0 = fails;
- 1 = acceptable;
- 2 = strong.

Do not average this into one overall percentage.

## Human-review flags
Escalate rather than penalise mechanically:
- deliberate asymmetry;
- expressive typography;
- intentionally dense expert content;
- long proper nouns;
- controlled terminology variation;
- editorial exceptions that improve the story.
