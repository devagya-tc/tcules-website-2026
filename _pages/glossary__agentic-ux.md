# Agentic UX

Agentic UX is the design of how a person delegates an objective and bounded authority to an AI system that can plan or execute multiple steps across tools or product state. When it matters: When an AI feature moves from suggesting a change to making it, the product needs clear delegation, permission and recovery.

Agentic UX differs from a chatbot that only returns text. An agent may form a plan, call tools, change records and continue after one step. The experience therefore needs plan visibility, permission, execution state, stop conditions, exception handling and recovery.

For example, an account-operations agent may prepare updates across several records. Agentic UX determines which steps require approval, how partial failure is shown and how the operator reverses a wrong change. A [human-in-the-loop review](/glossary/human-in-the-loop) is meaningful only when that operator has evidence, time and permission to intervene.

[AI Product UX](/glossary/ai-product-ux) covers the wider relationship between people and model behaviour. See how Tcules approaches [AI Copilots and Agents](/services/ai-product-ux/ai-copilots-agents).

## How is agentic UX used in practice? {#practice}

Agentic UX becomes relevant when an AI system can continue beyond one response. A product team has to decide what objective the person delegates, what tools or records the agent may touch, which actions need confirmation and what happens when only part of a plan succeeds. Those decisions shape the interface as much as the model capability does.

A useful review starts with one task and traces the agent from intent through plan, action, evidence and recovery. The [AI Copilots and Agents service](/services/ai-product-ux/ai-copilots-agents) applies that framing to product work.

## How does agentic UX differ from a chatbot interaction? {#comparison}

The table separates a conversational interface from an agent that can change product state.

| Interaction | What the system does | What the product must make clear |
|---|---|---|
| Chatbot or assistant response | Returns information or generated content | Source, uncertainty, editability and what the person should do next |
| Agentic interaction | Plans or executes several steps across tools or records | Delegated objective, authority, progress, approval points, failure handling and recovery |
